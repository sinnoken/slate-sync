## AprilTag (tag36h11 code table)

`web/sync-slate.html`, `web/sync-analyzer.html` and `tests/make_test_media.py` embed the tag36h11 code table and bit layout from [AprilRobotics/apriltag](https://github.com/AprilRobotics/apriltag) (`tag36h11.c`, commit `b7c0ebe9aa20f82ec7a828579004f9e706bfecd9`). The optional Python dependency [pupil-apriltags](https://github.com/pupil-labs/apriltags) wraps the same library.
