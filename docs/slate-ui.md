# 同步場記板的模式與操作介面

場記板主畫面的模式、各模式的畫面與聲音、控制列與設定頁的排版規則。AprilTag 的繪製與版面細節見 [visual-code.md](visual-code.md)，波形碼見 [waveform-code.md](waveform-code.md)，LTC 輸出見 [ltc.md](ltc.md)。

## 模式

主畫面第一層是五選一的模式，畫面與聲音由模式決定：

| 模式 | 畫面 | 聲音 | 分析器 |
|---|---|---|---|
| 時鐘 | 大字的時:分:秒:格（手機時鐘，free run）＋數字模式的畫面同步訊號 | 數字模式的聲音（嗶聲或波形碼） | 波形碼時可自動對時 |
| 正數 | 大字的經過時間＋同上 | 同上 | 同上 |
| 倒數 | 大字的剩餘時間＋同上 | 同上 | 同上 |
| Tag | AprilTag 全螢幕＋方波外框帶＋一行手機時鐘 | 波形碼 | 畫面碼與波形碼 |
| LTC | AprilTag 全螢幕＋方波外框帶＋一行目前輸出的 LTC 時間碼 | LTC | 畫面碼與 LTC |

- 正數、倒數、時鐘合稱「數字模式」，給人看與聽；Tag、LTC 給分析器自動對時，一律跟著手機時鐘，不計時。
- 靜音：主畫面的靜音鈕對五種模式都有效，會記住；靜音時只關聲音，畫面照常。
- 排程開始只用於正數與倒數。
- 進行中（計時或等待排程）切換模式的鎖定規則與 1.1.0 相同。

## 主畫面控制列

```
[時鐘][正數][倒數][Tag][LTC]          ← 第一層：五選一（分段按鈕）
（依模式的第二列）                      ← 倒數：長度選項、自訂、排程、開始／停止
                                         正數：排程、開始／停止
                                         時鐘、Tag、LTC：沒有第二列
一行提示（依模式）
```

- 靜音鈕放在右上角、設定鈕的左邊（頂列：SCENE 欄位、靜音、設定），樣式與設定鈕相同。

- 主畫面不顯示影格率，也沒有音訊切換；這兩項分別在設定頁與由模式決定。
- 第一層的五個按鈕在 390 px 寬的手機直拿時排成一行，不換行；橫拿時控制列的高度不增加。
- 提示一句話，說明目前模式的用途，例如 Tag：「給只拍到畫面的攝影機用：頭尾各拍 5–10 秒，分析器自動對時。」
- 點畫面隱藏按鈕（clean 模式）的行為不變。

## 設定頁

### 排版規則
1. 每個設定是一張卡片：標題、一行說明、控制項。區段標題只放短的分組名稱，不放說明。
2. 選取狀態只用一種樣式（白底黑字）；黃色只用於主要動作（「完成」）與警示。
3. 選項 4 個以內用分段按鈕，超過 4 個用格狀；「自動」等選項放在同一個格子裡，不另占一行。
4. 說明只講目前選中的選項，切換時跟著換。
5. 間距、字級、圓角沿用現有的設計 token，不新增。

### 分組
| 區段 | 設定 |
|---|---|
| 數字模式 | 聲音（嗶聲／波形碼，預設嗶聲）、畫面同步訊號（黑白方波／短閃白） |
| LTC | 影格率（格狀；時鐘的「格」數字也依此顯示）、DF／NDF（只在 29.97 系列可選） |
| 倒數 | 自訂長度 |
| 校準 | 畫面、聲音（每支手機做一次） |
| 外觀 | 配色、語言 |
| 其他 | 開啟同步分析器、重設所有設定 |

## 程式結構
- 場記板的編碼函式（`cycleK`、`waveHz` 與音高表、`waveBursts`、`ltcParams`、`countToTC`、`ltcBits`、`ltcChunk`、tag 碼表與 `drawTag` 的位元計算）放在 `src/core/slate.js`，由場記板、分析核心、測試與測試產生器共用。
- 場記板頁面改為範本 `src/web/sync-slate.html` 加打包後內嵌的 script（與分析器相同），建置成單一檔案 `dist/sync-slate.html`；`web/sw.js` 的快取清單不變。
- 測試與產生器直接 import，不再以 `vm` 從 HTML 載入。

## 驗收
- 波形碼的脈衝與載波、LTC 位元與取樣、tag 位元：連續兩天逐秒（LTC 逐格）與 1.1.0 相同。
- 五種模式的畫面與聲音符合上表；靜音鈕在五種模式都有效並記住。
- 舊版存下的設定值不認得時退回預設，不報錯。
- 四種語言的字串齊全（`npm run check`）；焦點移入、背景不可操作、Esc 關閉等無障礙行為與 1.1.0 相同。
- 390 × 844 直拿、844 × 390 與 667 × 375 橫拿，五種模式都沒有溢出或裁切。
- 以 `dist/` 安裝的 PWA 可離線開啟。
