# 波形碼格式規格

波形碼是給剪輯軟體的波形畫面「用眼睛讀」、也讓程式自動解讀的同步訊號。每秒一組，資訊只靠脈衝的**長度、數量與位置**表達，不依賴音量高低，因此能承受削波、限幅、自動增益與有損壓縮。

## 每秒的結構

所有時間以該秒的起點（真實時間的整秒）為 0。

| 元素 | 起點 | 長度 | 振幅 |
|---|---|---|---|
| 同步脈衝（一般秒） | 0 | 40 ms | 0.9 |
| 同步脈衝（每分鐘第 :00 秒） | 0 | 250 ms | 0.9 |
| 十位數組 | 100 ms（:00 秒為 300 ms） | 見下 | 0.45 |
| 個位數組 | 十位數組結束後 100 ms | 見下 | 0.45 |

- **對齊點**：同步脈衝的前緣就是真實時間的整秒。
- **數字 1–9**：該數量的短脈衝，每個 20 ms，週期 40 ms（間隔 20 ms）。
- **數字 0**：一個 100 ms 的寬脈衝。
- **一般秒**報該秒的秒數（01–59）；**:00 秒**改報**分鐘數**（00–59）。
- 每秒內容在 0.95 秒內結束，不會與下一秒重疊。

例：第 37 秒為「40 ms 同步脈衝 → 3 個短脈衝 → 7 個短脈衝」；12:35:00 為「250 ms 同步脈衝 → 3 個短脈衝 → 5 個短脈衝」。

## 載波

每個脈衝都是從相位 0 開始的正弦波，頻率每秒不同：

```
頻率 (Hz) = 600 + (((分 × 60 + 秒) × 7919) mod 19) × 80
```

範圍 600–2040 Hz，相鄰兩秒必不相同。頻率在波形畫面上看不出來，但可避免剪輯軟體以音訊自動同步時錯開整數秒（實測錯開 1 秒時的相關度由 92–97% 降到 0–3%）。

## 解讀規則（分析器）

1. 4 ms 移動平均取音量包絡；門檻為前後 0.6 秒內最大音量的 25%，以跟隨增益變化。
2. 長 25–70 ms 的脈衝視為一般同步、200–300 ms 視為分鐘同步。
3. 前緣：第一次超過脈衝振幅 40% 的位置（取樣間內插），再扣除該載波頻率下正弦波由 0 升至 40% 的時間；可避開 AAC／MP3 的預回音。
4. 數字組須符合起點（±20 ms）、脈衝長度（10–35 ms；0 為 80–125 ms）與間距（34–46 ms），否則整秒捨棄，現場聲音因此不會被誤判。
5. 連續各秒必須依序遞增且間隔約 1 秒；讀到分鐘標記時換算為一小時內的秒數，否則為一分鐘內的秒數。

## 產生端

`web/sync-slate.html` 的 `waveBursts()`（每秒的脈衝清單）、`waveHz()`（載波頻率）與 `wavePlay()` 是本規格的參考實作。`wavePlay()` 以一個振盪器加上精確到取樣點的音量閘門產生每秒的脈衝：振盪器在同步脈衝起點以相位 0 開始，因此前緣與逐點計算的正弦波相同；數字脈衝只依長度解讀，相位不影響。每秒的音訊由獨立的排程器提前約 0.7 秒排入音訊時鐘，在整秒播放，並套用使用者設定的聲音延遲補償。
